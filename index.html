// how it is built

Stack

Four static HTML files and one stylesheet. No backend, no framework and no runtime dependencies — the only moving part is a single script that reads GitHub directly from your browser.

markup

HTML

Every page is a real file, so the content exists before any script runs.

styling

Tailwind CSS

Compiled to one stylesheet by the Tailwind CLI, with the palette as theme tokens.

behaviour

Vanilla JS

Small ES modules for the clock, the reveals, the projects grid and the explain popups.

data

GitHub API

Called from the browser and cached for five minutes, with a snapshot when it cannot be reached.
